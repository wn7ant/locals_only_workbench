# Locals-Only-Workbench

**Locals Only WorkBench** — **lowb.us** — is a local-first project for replacing narrow, single-purpose apps and fragile cloud dependencies with rebuildable workflows built from standard files, open tools, Docker, Git, Markdown, and self-hosted services.

The goal is simple:

> Keep your work portable, understandable, backed up, and under your control.

This repo is the public mirror of the Locals Only WorkBench recipes and configuration examples. The working source of truth lives locally in Gitea. GitHub is used as a public mirror so others can read, clone, adapt, and learn from the work.

---

## What this project is

Locals Only WorkBench documents practical recipes for building your own local workbench instead of depending on one fragile app, subscription platform, or cloud service.

The project focuses on:

- Local-first workflows.
- Standard file formats.
- Self-hosted Docker services.
- VS Code / VSCodium-centered workbenches.
- Markdown, CSV, SVG, PDF, and Git.
- Rebuildable configurations.
- Mac and Linux users.
- Practical app-replacement recipes.

This is not about refusing all commercial software. Good tools are worth paying for.

This project is about avoiding unnecessary lock-in and making sure your work can survive app changes, subscription changes, hardware failure, and platform drift.
